# Azel M. Villanueva — Personal CV Portfolio

A personal CV website showcasing my profile, education, technical skills, academic development experience, and certifications. Created for IT 415 — Application Development and Emerging Technologies.

## Links

- **Live website:** Pending Vercel deployment
- **Source code:** [Personal-cv](https://github.com/Zel-jpeg/Personal-cv)
- **GitHub profile:** [Zel-jpeg](https://github.com/Zel-jpeg)

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Light and dark themes with saved preferences
- Section navigation with active section highlighting
- Hover effects and scroll animations with reduced-motion support
- Print-friendly CV layout
- Email and GitHub contact links
- Expanding featured work panels and project cards with previews, code links, and demos
- Scrolling technology icons and an expandable skills list
- Diagonal light/dark theme transition in supported browsers
- Interactive personal photo stack (profile photos used temporarily)
- Public GitHub contribution grid with an unavailable-data fallback

## Technologies

- React
- TypeScript
- Vite
- Custom CSS
- Lucide React and React Icons

## Run locally

With Node.js 22.12+ installed:

```sh
git clone https://github.com/Zel-jpeg/Personal-cv.git
cd Personal-cv
npm install
npm run dev
```

Open the local URL shown in the terminal.

To build and preview the production version:

```sh
npm run build
npm run preview
```
